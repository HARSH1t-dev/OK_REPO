🔭 Issue Scout

Active, substantial open-source issues, rated for true difficulty, with an implementation plan. Stale and trivial “good first issues” are filtered out.

Filters run in your browser against the GitHub API.

Settings

Keys stay in this browser’s localStorage and are only sent to GitHub, Google or Groq. Use a fine-grained GitHub token with read-only public access. Marking maintainer picks needs write access to issues on that repo.
